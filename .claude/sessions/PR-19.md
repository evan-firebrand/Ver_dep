# Session Note — PR-19 Series Pages

## What was built

`/series` index and `/series/[slug]` dynamic route for filtering events by the `series` column in Supabase.

## Discoveries

**No new Supabase query needed.** `NolaEvent.series` is already an `EventSeries[]` array returned by `getEvents()`. Filtering happens in-memory after the cached fetch — zero extra round-trips.

**`generateStaticParams` just works.** All 5 series slugs are pre-generated at build time, making each series page fully PPR-eligible from the first request.

**Slug utilities centralised in `src/lib/series.ts`.** If a new `EventSeries` is added to `types.ts`, `SERIES_SLUGS` and `ALL_SERIES` in `series.ts` need updating too — the TypeScript `Record<EventSeries, string>` type enforces completeness at compile time (adding a new series without adding its slug is a type error).
